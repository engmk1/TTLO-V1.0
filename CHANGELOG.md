# Changelog

## v1.0 – 28 Oct 2026
First release of the rebuilt TTLO.
- 3D and 2D loading view (Low Bed with main unit and rollers, Flat Beds, 40ft HC containers), VOLTAMP factory front scene, light and dark mode.
- Excel packing box list import (.xlsx, .xls, .csv) with main unit, rollers and oil-drum recognition from any common wording.
- Allocation with payload checked per truck; Oman and imported cargo kept on separate trucks.
- Manual editing: drag in 2D, move between trucks, stacking, rotate, auto-pack, improve balance, undo / redo.
- Load balance check (estimated CoG, front/rear and left/right split).
- PDF loading plan (complete, Flat Bed only, Low Bed / ODC only) with direct download.
- My Projects saved in the browser; export / open `.ttlo.json` files; Excel template download.
- Truck configuration with saved personal defaults and a one-click restore of the default sizes.
- Works without internet: all libraries and fonts are stored with the site.
